## Вопросы

Источник вопросов — таблица `Банк_вопросов.xlsx`, лист «Вопросы».

- **Поправить вопрос.** Исправьте текст прямо в ячейке и сохраните файл. Номер в колонке A не меняйте: по нему в приложении хранится прогресс.
- **Убрать вопрос из приложения.** В колонке N «Проверено юристом» выберите «Убрать» или «Исправить». Такие вопросы в приложение не попадают, остальные попадают.
- **Добавить вопрос.** Допишите строку внизу таблицы и дайте ей следующий свободный номер. В колонке L укажите документ точно так же, как в соседних строках: по этому названию вопрос попадает в нужную тему.

Если в таблице ошибка (нет номера, номер повторяется, неизвестный формат или документ), публикация остановится. Текст ошибки будет во вкладке **Actions** на GitHub.

Для «Выбора ответа» верный ответ пишется в колонке I так: «Б — текст варианта». Для «Вписать ответ» в колонке J через точку с запятой перечисляются все написания, которые нужно засчитывать. Кроме того, приложение не учитывает регистр, ё/е и кавычки и прощает одну опечатку в длинных словах.

## Головоломки

Каждый набор — отдельный файл `puzzles/<набор>.json`. Одна головоломка выглядит так:

```json
{
  "id": "n02",
  "prompt": "Отрывок какого гимна звучит в обратной перемотке?",
  "audio": { "src": "audio/gaudeamus.mp3", "reverse": true },
  "hint": "Его поют студенты по всему миру",
  "answer": "«Gaudeamus igitur» — гимн студентов",
  "note": "Пояснение, которое показывается вместе с ответом"
}
```

Обязательны поля `id` (уникальный в наборе), `prompt` и `answer`. Остальные поля можно сочетать как угодно:

- `"image": "puzzles/папка/файл.webp"` — картинка задания, `"answerImage"` — картинка к ответу;
- `"text"` — текст задания (цитата, анкета, уравнение). Перенос строки — `\n`;
- `"rebus"` — короткий ребус из букв и эмодзи, показывается крупно;
- `"t9"` — цифры для шифра кнопочного телефона, рядом рисуется клавиатура;
- `"swatches": [{ "hex": "#0039A6", "name": "Синий" }]` — цветные квадраты;
- `"calendar": { "year": 2026, "month": 9, "marks": [30] }` — календарь с обведёнными днями;
- `"audio": { "src": "audio/файл.mp3", "reverse": true, "start": 10, "end": 25 }` — отрывок. `reverse: true` проигрывает его задом наперёд, `start` и `end` — секунды.

Чтобы добавить свою песню или гимн, например гимн «Общаги РФ», положите файл в `apps/web/public/audio/` (mp3 или m4a) и сошлитесь на него в `"audio"`. Обратное проигрывание приложение делает само, переворачивать файл не нужно. Используйте записи, которые вам разрешено публиковать: приложение открыто для всех.

`audio/gaudeamus.mp3` — мелодия студенческого гимна «Gaudeamus igitur», синтезированная по нотам. Мелодия народная, ей больше двухсот лет, поэтому её можно свободно использовать.

## Исходники банка

Папка `q/` и скрипт `tools/build.py` нужны, чтобы генерировать новые вопросы пачками. Запуск `python tools/build.py` (нужны Python 3 и `pip install openpyxl`) добавляет в конец таблицы только новые вопросы и не трогает строки, которые вы уже правили.
