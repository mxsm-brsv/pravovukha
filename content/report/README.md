# Сообщения о неточностях

Под каждым пояснением в приложении есть ссылка «Неточность? Сообщить». Человек выбирает, что не так (неверный ответ, неточная формулировка, устаревшая норма, другое), и может написать комментарий. Сообщение анонимное: имя и аккаунт Telegram не передаются.

Куда уходят сообщения, задаётся в файле `apps/web/public/config.json`:

```json
{
  "reportUrl": "",
  "reportContact": ""
}
```

Пока оба поля пустые, текст сообщения просто копируется в буфер обмена. Ниже описаны два варианта настройки, бот и токен не нужны ни в одном из них.

## Вариант 1. Google-таблица и письмо на почту (рекомендуется)

Каждое сообщение становится строкой в вашей таблице. В колонке «Статус» можно отмечать: «Новая», «В работе», «Исправлено» или «Отклонено». Если указать почту, о каждом сообщении будет приходить письмо.

1. Создайте пустую Google-таблицу, например «Правовуха — неточности».
2. В таблице откройте **Расширения → Apps Script**.
3. Удалите всё, что там написано, и вставьте содержимое файла `apps-script.gs` из этой папки.
4. В строке `const NOTIFY_EMAIL = '';` впишите свою почту между кавычками. Если письма не нужны, оставьте строку как есть.
5. Нажмите **Сохранить** (значок дискеты).
6. Справа вверху нажмите **Начать развертывание → Новое развертывание**. Нажмите на шестерёнку и выберите тип **Веб-приложение**. Укажите:
   - «Запуск от имени»: **Я**;
   - «У кого есть доступ»: **Все**.
7. Нажмите **Начать развертывание** и разрешите доступ к своему аккаунту. Google предупредит, что приложение не проверено: нажмите **Дополнительные настройки → Перейти на страницу…**. Это ваш собственный скрипт.
8. Скопируйте **URL веб-приложения**: он заканчивается на `/exec`.
9. Вставьте этот адрес в `apps/web/public/config.json` в поле `"reportUrl"` и отправьте изменения: в GitHub Desktop нажмите **Commit to main → Push origin**.

Проверка: откройте адрес из шага 8 в браузере. Должна появиться надпись «Приём сообщений работает». Затем отправьте неточность из приложения — в таблице появится лист «Неточности» с новой строкой.

## Вариант 2. Сообщение вам в Telegram

Впишите в поле `"reportContact"` своё имя пользователя Telegram без @, например `"reportContact": "ivanov"`. Приложение скопирует текст и откроет чат с вами, а человеку останется вставить текст и отправить. В этом варианте сообщение уходит от имени пользователя, то есть перестаёт быть анонимным. Сохранять сообщения в таблицу придётся вручную.
