# С правовухой на ты

Бесплатный тренажёр правовой грамотности для конкурсов Профсоюза образования в виде Telegram Mini App. Устроен по образцу «ПДД 2027» и Quizlet: вопросы с пояснениями, экзамен, головоломки. Регистрации, рейтингов и рекламы нет.

Что внутри:

- **Учить:** 1129 вопросов по 41 документу. Тренировка по 10 вопросов, карточки, работа над ошибками, список вопросов с поиском и экзамен по образцу ПДД (20 вопросов за 20 минут, не больше двух ошибок).
- **Играть:** режимы «2 к 1» и «Правовой биатлон» по Положению о конкурсе «Ты — лидер», а также 143 головоломки: ребусы, логотипы, шифры, календари и звуки, в том числе задом наперёд.
- **Сообщить о неточности:** анонимная ссылка под каждым пояснением, настройка описана в `content/report/README.md`.

- **Сайт:** статический, публикуется на GitHub Pages. Своего сервера и базы данных нет.
- **Прогресс:** хранится в Telegram CloudStorage пользователя. Если приложение открыто в обычном браузере, прогресс хранится в localStorage.
- **Вопросы:** хранятся в таблице `content/Банк_вопросов.xlsx` и при сборке превращаются в JSON. Поправили таблицу, сделали Commit и Push — через пару минут правка в приложении. Внутри приложения нет ИИ и нет загрузки файлов.

## Как устроен репозиторий

```
content/           вопросы (xlsx), темы, головоломки, настройка сообщений о неточностях
apps/web/          Mini App: Next.js 16 (статический экспорт), React 19, Tailwind 4, Motion
  app/             экраны: главная, «Учить» (темы, тренировка, карточки, экзамен), «Играть», профиль
  scripts/         export-content.mjs — собирает public/data/*.json из content/ перед сборкой
  public/          картинки головоломок, звуки, config.json (куда слать сообщения о неточностях)
  src/tma/         обёртка над telegram-web-app.js: кнопки, вибрация, CloudStorage
  src/components/  вопрос, головоломка, проигрыватель, общие элементы интерфейса
  src/stores/      состояние (Zustand): профиль, прогресс по темам, рекорды
packages/shared/   логика без интерфейса: проверка ответов, прогресс, экзамен, серия дней (+ тесты)
.github/workflows/ публикация на GitHub Pages
```

## Публикация

Сайт публикуется сам при каждом изменении в ветке `main` (файл `.github/workflows/deploy.yml`). Ход публикации виден во вкладке **Actions**, через 2–3 минуты сайт доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Первый запуск, один раз:

1. Репозиторий должен быть **открытым**: на бесплатном тарифе GitHub Pages работает только для открытых репозиториев.
2. **Settings → Pages → Source: GitHub Actions.** Готовые шаблоны, которые GitHub предложит ниже, не нужны.
3. Если файла `.github/workflows/deploy.yml` в репозитории ещё нет, создайте его на сайте GitHub: **Add file → Create new file**, имя `.github/workflows/deploy.yml`, содержимое — из этого репозитория или из чата, затем **Commit changes**.
4. Если запуск во вкладке **Actions** упал из-за того, что Pages ещё не были включены, откройте его и нажмите **Re-run all jobs**.

Обычные изменения через GitHub Desktop: **Commit to main** → **Push origin**. Если что-то меняли на сайте GitHub, сначала **Fetch origin** → **Pull origin**.

## Настройка бота в @BotFather

Боту не нужен сервер и не нужен токен в коде: Mini App открывается по ссылке на сайт.

1. `/mybots` → выберите бота → **Bot Settings → Configure Mini App → Enable Mini App**. В качестве адреса укажите адрес сайта со слешем на конце, например `https://<логин>.github.io/pravovukha/`.
2. **Bot Settings → Menu Button**: та же ссылка, текст кнопки «Учить».
3. По желанию: **Edit Bot → Edit Description / About / Botpic** — описание и аватар бота.

После этого приложение открывается кнопкой в чате с ботом и по ссылке `https://t.me/<бот>?startapp`.

Ссылки на конкретные экраны:

| Ссылка | Экран |
|---|---|
| `https://t.me/<бот>?startapp` | Главная |
| `https://t.me/<бот>?startapp=profile` | Профиль |
| `https://t.me/<бот>?startapp=goal` | Дневная цель |

Токен бота никуда записывать не нужно. Если он где-то засветился, отзовите его в @BotFather командой `/revoke`.

## Разработка на своём компьютере

Нужны Node.js 22 и pnpm 10 (`corepack enable` включает pnpm, который идёт вместе с Node.js).

```bash
pnpm install
pnpm dev          # http://localhost:3000 — приложение в режиме браузера
pnpm check        # типы и тесты
pnpm build        # статическая сборка в apps/web/out
```

В браузере вместо кнопок Telegram показываются запасные: главная кнопка внизу экрана и стрелка «Назад» вверху. Тема берётся из настроек системы.

Чтобы проверить приложение внутри Telegram до публикации, подойдёт тестовый сервер Telegram или туннель (например, `cloudflared tunnel --url http://localhost:3000`). Адрес туннеля указывается в BotFather у отдельного тестового бота.

## Ключи в CloudStorage

Telegram разрешает в ключах только `A-Z a-z 0-9 _ -` (до 128 символов), значение — до 4096 символов.

| Ключ | Что хранит |
|---|---|
| `profile_v1` | настройки, дневная цель, серия дней, ответы за сегодня |
| `p_<тема>` | прогресс по теме: номер вопроса и уровень (`12.2,15.1`): 1 — ошибка, 2 — верно, 3 — выучен |
| `games_v1` | рекорды «2 к 1» и биатлона, экзамены, отгаданные головоломки |
